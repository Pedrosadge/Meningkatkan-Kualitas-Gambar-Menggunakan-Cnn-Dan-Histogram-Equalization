Proyek ini merupakan pengembangan program untuk meningkatkan kualitas gambar menggunakan Convolutional Neural Network (CNN) dan Histogram Equalization (HE). Program ini menggabungkan kemampuan CNN dalam mengurangi noise dan meningkatkan fitur gambar dengan penyesuaian kontras dari HE untuk menghasilkan gambar yang lebih jelas dan menarik secara visual. Antarmuka yang user-friendly memungkinkan pengguna dengan keahlian teknis minimal untuk menyempurnakan gambar mereka secara efektif.
